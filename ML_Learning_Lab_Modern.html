01

K-Nearest Neighbor

จำแนกประเภทข้อมูลใหม่จาก “เพื่อนบ้านที่ใกล้ที่สุด” ด้วย Majority Vote

Supervised · Classification
1. Theory · หลักการสำคัญ

KNN ใช้การคำนวณระยะห่างเพื่อวัดความคล้ายคลึงระหว่างจุดข้อมูลใหม่กับชุดข้อมูลสอน (Training Data) จากนั้นทำการคัดเลือกเพื่อนบ้านที่มีระยะทางใกล้ที่สุดจำนวน K จุด และใช้เสียงข้างมาก (Majority Vote) เพื่อสรุปว่าข้อมูลใหม่ควรจัดอยู่ในคลาสใด

Distance = √Σ(x₁ᵢ − x₂ᵢ)²
2. ML Workflow · ลำดับขั้นตอน
1
Input Data

รับพิกัดจุดข้อมูลทดสอบใหม่ (Feature X, Y)

2
Calculate Distance

คำนวณ Euclidean Distance เทียบกับจุดใน Training Set ทั้งหมด

3
Select Nearest K

เรียงลำดับระยะทางจากน้อยไปมาก แล้วเลือก K จุดที่ใกล้ที่สุด

4
Majority Vote

คลาสที่ได้รับเสียงโหวตมากที่สุดกลายเป็นผลการทำนาย

3. Calculation Example · ตัวอย่างการคำนวณแบบ Step-by-step

Euclidean Distance + Majority Vote

ตัวอย่างตามทฤษฎี: ข้อมูลทดสอบ Test Data = [4, 3, 4, 3, 4], ข้อมูลฝึกสอน Training Data = [3, 3, 5, 2, 4] กำหนดค่า K = 3

1
หาผลต่างของแต่ละมิติ (Feature Differences)

นำค่าแต่ละ Feature ของ Test Data ลบด้วย Training Data ทีละตำแหน่ง

[4−3, 3−3, 4−5, 3−2, 4−4] = [1, 0, −1, 1, 0]
2
คำนวณ Euclidean Distance

ยกกำลังสองของความต่างในแต่ละมิติ นำมารวมกัน แล้วถอดรากที่สอง

√(1² + 0² + (−1)² + 1² + 0²) = √3 ≈ 1.732
3
เลือกเพื่อนบ้านที่ใกล้ที่สุด K = 3 จุด

ระยะห่างที่ใกล้ที่สุด 3 อันดับแรกคือ 1.732, 2.449 และ 2.449 ซึ่งเป็นข้อมูล Class A ทั้งหมด

4
ลงคะแนนเสียง (Majority Voting)

Class A ได้คะแนนเสียง 3 จาก 3 เสียง จึงสรุปการทำนายเป็น Class A

ผลลัพธ์จากตัวอย่างการคำนวณ (Benchmark) Predicted = Class A · Accuracy = 100%

02

KNN Regression

พยากรณ์ค่าตัวเลขต่อเนื่องจากรูปแบบในอดีตที่คล้ายคลึงกัน (Sliding Window)

Supervised · Regression
1. Theory · หลักการสำคัญ

KNN Regression ใช้การคำนวณระยะห่างเวกเตอร์เพื่อหารูปแบบหน้าต่างข้อมูลในอดีตที่มีความใกล้เคียงที่สุด แต่แทนที่จะลงคะแนนโหวตคลาส ระบบจะนำค่าเป้าหมาย (Target) ของเพื่อนบ้าน K ชุดที่คล้ายที่สุดมาคำนวณหาค่าเฉลี่ยเลขคณิต เพื่อทำนายราคาวันถัดไป

ŷ = (y₁ + y₂ + … + yₖ) / K
2. ML Workflow · ลำดับขั้นตอน
1
Sliding Window

สร้างเวกเตอร์ Feature ขนาด 5 วัน เพื่อเป็นรูปแบบอ้างอิง

2
Compare Patterns

เทียบระยะห่างของรูปแบบปัจจุบันกับหน้าต่างในอดีต

3
Select K Windows

เลือก K ช่วงเวลาในอดีตที่มี Distance ต่ำที่สุด

4
Average Target

หาค่าเฉลี่ยของราคาวันถัดไปของเพื่อนบ้านเพื่อสรุปคำพยากรณ์

3. Calculation Example · ตัวอย่างการคำนวณแบบ Step-by-step

Sliding Window + Target Averaging

ตัวอย่างตามทฤษฎี: ราคาปิดย้อนหลัง 6 วัน = [183, 184, 185, 186, 187, 188] โดยใช้ Sliding Window ขนาด 5 วัน

1
กำหนด Feature และ Target สำหรับโมเดล

ใช้ 5 วันแรกเป็นข้อมูลนำเข้า และวันที่ 6 เป็นค่าผลลัพธ์จริงที่ต้องการเรียนรู้

Feature Window = [183, 184, 185, 186, 187] → Target (Next Day) = 188
2
ค้นหา K เพื่อนบ้านที่มีรูปแบบใกล้เคียงที่สุด

สมมติกำหนด K = 3 และพบว่าค่า Target ของ 3 เพื่อนบ้านที่คล้ายที่สุดคือ 185, 186 และ 187

3
คำนวณค่าเฉลี่ยเลขคณิต

KNN Regression จะหาค่าเฉลี่ยแทนการลงคะแนนเสียงโหวต

ŷ = (185 + 186 + 187) / 3 = 558 / 3 = 186.00
ผลลัพธ์จากตัวอย่างการคำนวณ (Benchmark) Predicted Close = 186.00

03

K-Means Clustering

จัดกลุ่มข้อมูล Unsupervised โดยดึงดูดข้อมูลเข้าหาจุดศูนย์กลาง (Centroid)

Unsupervised · Clustering
1. Theory · หลักการสำคัญ

K-Means เริ่มต้นจากการกำหนดจำนวนกลุ่ม K และวางตำแหน่ง Centroid จากนั้นคำนวณระยะห่างเพื่อจัดสมาชิกแต่ละจุดเข้ากลุ่มที่ใกล้ที่สุด แล้วคำนวณค่าเฉลี่ยพิกัดใหม่เพื่อย้าย Centroid กระบวนการนี้จะวนซ้ำแบบ Iterative จนตำแหน่งของ Centroid แทบไม่มีการเปลี่ยนแปลง (Converged)

Centroid = mean(points in cluster)
2. ML Workflow · ลำดับขั้นตอน
1
Initialize

กำหนดจำนวนกลุ่ม K และสุ่มเลือกตำแหน่ง Centroid เริ่มต้น

2
Assign Clusters

จัดจุดข้อมูลทุกจุดเข้าสู่กลุ่มของ Centroid ที่อยู่ใกล้ที่สุด

3
Update Centroids

คำนวณค่าเฉลี่ยใหม่ของสมาชิกในแต่ละกลุ่ม แล้วเลื่อนตำแหน่ง Centroid

4
Iterate to Convergence

ทำซ้ำขั้นตอน Assign และ Update จนกว่า Centroid จะหยุดเคลื่อนที่

3. Calculation Example · ตัวอย่างการคำนวณแบบ Step-by-step

Distance Assignment + Centroid Recalculation

ตัวอย่างตามทฤษฎี: กำหนด K = 2, พิจารณาจุดข้อมูล A(2,3) และ Centroid เริ่มต้น C₁(2,3), C₂(9,9)

1
คำนวณระยะห่างจากจุด A ไปยังแต่ละ Centroid
d(A, C₁) = √((2−2)² + (3−3)²) = 0.00
d(A, C₂) = √((2−9)² + (3−9)²) ≈ 9.22
2
จัดจุด A เข้ากลุ่ม (Cluster Assignment)

เนื่องจาก 0.00 < 9.22 จุด A จึงถูกกำหนดให้อยู่ใน Cluster 1

3
คำนวณค่าเฉลี่ยใหม่ของกลุ่ม (Centroid Update)

สมมติ Cluster 1 มีสมาชิกร่วมได้แก่ A(2,3), B(3,4), C(4,5)

x̄ = (2 + 3 + 4) / 3 = 3.00 · ȳ = (3 + 4 + 5) / 3 = 4.00
4
ทำซ้ำจนตำแหน่งคงที่ (Convergence)

Centroid ใหม่ของ Cluster 1 เลื่อนไปอยู่ที่ (3.00, 4.00) จากนั้นทำการจัดกลุ่มใหม่และคำนวณซ้ำ

ผลลัพธ์จากตัวอย่างการคำนวณ (Benchmark) Updated C₁ = (3.00, 4.00) → Repeat until Converged

01

ทำความเข้าใจ · K-Nearest Neighbor (KNN)

ตอบคำถามว่า: “ข้อมูลที่เข้ามาใหม่นี้ ควรจัดอยู่ในกลุ่มไหน?” ผ่านตัวอย่างชีวิตประจำวัน

KNN ใช้สำหรับจำแนกข้อมูลใหม่ โดยเปรียบเทียบความใกล้เคียงกับข้อมูลเดิมที่มีอยู่จำนวน K ตัว แล้วอาศัยเสียงข้างมาก (Majority Vote) ในการตัดสินกลุ่ม

ตัวอย่างชีวิตจริง: ร้านผลไม้จำแนกผลไม้ชนิดใหม่

ร้านเก็บข้อมูลผลไม้เดิมไว้โดยวัดจาก “น้ำหนัก” และ “ระดับความหวาน” เมื่อมีผลไม้ลูกใหม่เข้ามาและยังไม่ทราบชนิด

ข้อมูลน้ำหนักความหวาน (1–10)ประเภทที่รู้แล้ว
ผลไม้ A150 กรัม7แอปเปิล
ผลไม้ B160 กรัม8แอปเปิล
ผลไม้ C140 กรัม7แอปเปิล
ผลไม้ D110 กรัม5ส้ม
ผลไม้ E120 กรัม6ส้ม
ผลไม้ใหม่145 กรัม7?
1. มีข้อมูลใหม่ผลไม้ใหม่หนัก 145g ความหวาน 7
2. หาเพื่อนบ้านคำนวณระยะห่างเทียบกับผลไม้เดิม
3. กำหนด K = 3เลือก 3 ผลที่ใกล้ที่สุด ได้แอปเปิล 3 ลูก
4. โหวตแอปเปิล 3 เสียง → ทำนายเป็นแอปเปิล
สรุปใจความสำคัญ KNN = “ถามเพื่อนบ้านที่ใกล้ที่สุด” → กลุ่มไหนอยู่ใกล้เรามากที่สุด เราน่าจะอยู่กลุ่มนั้น

ตัวอย่างนี้สร้างขึ้นเพื่ออธิบายแนวคิด ในงานจริงมักต้องเตรียมข้อมูล (Data Normalization) ก่อนวัดระยะทาง

02

ทำความเข้าใจ · KNN Regression

ตอบคำถามว่า: “ค่าของข้อมูลใหม่น่าจะประมาณเท่าไร?” ผ่านตัวอย่างการประเมินราคาห้องเช่า

KNN Regression ใช้สำหรับประมาณค่าตัวเลขต่อเนื่อง โดยหารูปแบบข้อมูลเก่าที่มีลักษณะใกล้เคียงที่สุด K ตัว แล้วนำค่าผลลัพธ์ของเพื่อนบ้านเหล่านั้นมาหาค่าเฉลี่ย แทนการใช้การโหวต

ตัวอย่างชีวิตจริง: การประมาณค่าเช่าห้องพัก

เรามีประวัติห้องเช่าเดิมโดยดูจาก “ขนาดห้อง” และ “ระยะห่างจากมหาวิทยาลัย” เมื่อมีห้องใหม่เข้ามาและต้องการประเมินราคา

ห้องขนาดห่างมหาวิทยาลัยค่าเช่าจริง
ห้อง A25 ตร.ม.1.0 กม.5,500 บาท
ห้อง B27 ตร.ม.1.2 กม.5,800 บาท
ห้อง C30 ตร.ม.1.5 กม.6,200 บาท
ห้อง D45 ตร.ม.4.0 กม.9,000 บาท
ห้องใหม่28 ตร.ม.1.3 กม.?
1. มีห้องใหม่ขนาด 28 ตร.ม. ห่างมหาวิทยาลัย 1.3 กม.
2. หาเพื่อนบ้านหาห้องที่มีขนาดและทำเลใกล้เคียงที่สุด
3. กำหนด K = 3ได้ห้อง A, B, C ราคา 5.5k / 5.8k / 6.2k
4. หาค่าเฉลี่ย(5,500 + 5,800 + 6,200) ÷ 3 ≈ 5,833 บาท
สรุปใจความสำคัญ KNN Regression = “ถามเพื่อนบ้านเหมือนกัน” แต่ไม่โหวต → นำค่าตัวเลขมาเฉลี่ยเลขคณิต

ในงานจริงมักต้องทำ Feature Scaling เพื่อปรับหน่วยของขนาดและระยะทางให้สมดุลกันก่อนคำนวณ

03

ทำความเข้าใจ · K-Means Clustering

ตอบคำถามว่า: “ข้อมูลทั้งหมดสามารถแบ่งออกเป็นกลุ่มพฤติกรรมอะไรได้บ้าง?” โดยไม่มีเฉลยล่วงหน้า

K-Means ใช้สำหรับจัดกลุ่มข้อมูลที่ยังไม่มีป้ายกำกับ (Unsupervised) โดยระบุจำนวนกลุ่ม K ที่ต้องการ จากนั้นระบบจะสร้างจุดศูนย์กลาง Centroid และขยับปรับตำแหน่งแบบวนซ้ำจนกลุ่มนิ่ง

ตัวอย่างชีวิตจริง: ร้านค้าจัดกลุ่มลูกค้าตามพฤติกรรมการซื้อ

ร้านมีข้อมูล “ความถี่ที่มาซื้อต่อเดือน” และ “ยอดใช้จ่าย” โดยยังไม่ได้ระบุว่าใครเป็นลูกค้าประเภทไหน

ลูกค้ามาซื้อ/เดือนยอดใช้จ่าย/เดือนกลุ่มก่อนรัน
ลูกค้า A1 ครั้ง300 บาทยังไม่รู้

1. กำหนด K = 2ระบุว่าต้องการแบ่งลูกค้าออกเป็น 2 กลุ่ม
2. วาง Centroidระบบวางจุดศูนย์กลางเริ่มต้นของแต่ละกลุ่ม
3. จัดกลุ่ม & ย้ายลูกค้าเลือก Centroid ที่ใกล้ตนเอง จากนั้นย้ายจุดศูนย์กลาง
4. ทำซ้ำจนนิ่งแยกได้ชัดเจนเป็นกลุ่ม “ซื้อน้อย/จ่ายน้อย” และ “ซื้อบ่อย/จ่ายสูง”
สรุปใจความสำคัญ K-Means = “ให้ข้อมูลจัดกลุ่มกันเอง” → เรากำหนดแค่จำนวนกลุ่ม K ส่วนการค้นพบแพทเทิร์นเป็นหน้าที่ของอัลกอริทึม
